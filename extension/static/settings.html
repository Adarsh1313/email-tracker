    Gmail sync (optional)

    Read-only access finds replies and bounces. Nothing is sent or changed in your mailbox.

    Tip: reading your own Sent copy in the Gmail phone app can't be detected, so it shows as an open. Open the email on the dashboard, hover that open in its timeline and choose That was me.

    How to turn this on (about 10 minutes, once)
    1. In Google Cloud Console, create a project and enable the Gmail API.
    2. Set up the OAuth consent screen as External, leave it in Testing, and add your Gmail address as a test user. Add the scope gmail.readonly.
    3. Create an OAuth client ID of type Chrome extension. For its Item ID use your extension ID:
    4. Put the client ID in extension/local.config.json as oauthClientId, run npm run build in extension/, and reload the extension.
    5. Come back here and press Connect Gmail.

    Testing-mode Google apps expire access every 7 days; press Reconnect when asked.
